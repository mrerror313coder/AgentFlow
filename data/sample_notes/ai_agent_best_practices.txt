An AI agent is a loop, not a single prompt. The loop observes a goal, chooses a tool, reads the tool result, and decides the next step. Tool use should be narrow and typed: a search skill returns documents, a review skill returns findings, and the model is asked to interpret those results rather than invent them. Planning works best when the plan is written down and updated after every observation. A hidden plan inside one long completion is hard to debug when the model skips a step.

Memory needs an owner. Short-term memory is the current conversation. Long-term memory is a store the agent queries on purpose, such as notes, tickets, or a retrieval index. Dumping the entire history into every prompt crowds out the actual task. Error recovery belongs in the harness. If a tool times out, the loop should record the failure and retry or switch paths. The model should not be trusted to announce that a failed call succeeded. Human-in-the-loop patterns pause the loop before a destructive action, a public post, or a spend of money. The person sees the proposed action and the evidence, then approves or edits it. Agents that ship in real teams log every tool call, keep secrets out of prompts, and make the stop condition explicit so the loop cannot run forever.
